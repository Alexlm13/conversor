# Conversor de temperaturas

**Conversor de temperaturas** es una aplicación de línea de comandos escrita en Python que convierte un valor de temperatura entre tres unidades:

| Unidad | Símbolo |
|--------|---------|
| Celsius | `C` |
| Fahrenheit | `F` |
| Kelvin | `K` |

## ¿Qué hace?

Le indicas un valor, la unidad en la que está y la unidad a la que quieres convertirlo, y el programa muestra el resultado con dos decimales.

```
python conversor.py 100 C F
100 °C = 212.00 °F
```

## Características

- Convierte entre cualquier pareja de unidades (C, F, K).
- No necesita librerías externas: solo Python.
- Avisa con un mensaje claro si el número o la unidad no son válidos.
